# Standalone staging area

This is a staging area for original replacement art. The files under
`mod/assets/` are generated by `tools/generate-standalone-placeholders.ps1`
from geometric primitives and literal colours, without loading existing art.
They are intentionally rough placeholders. The active Hexen mod does not use
them; see [`docs/standalone/resource-map.md`](../../../docs/standalone/resource-map.md)
before connecting any file to a runtime sprite or texture name.

Do not add the local, ignored `mod/assets/textures/sky/` drafts or map WADs to
a public standalone package until their provenance and embedded dependencies
have been reviewed. The standalone game still requires independent maps,
enemies, player classes, resources, branding, and engine configuration.
