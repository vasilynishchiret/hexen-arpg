# Release licensing audit: built-in Hexen status bar

Reviewed on 2026-11-21 and updated on 2026-11-22 for branch `fix/native-hexen-statusbar`. This records evidence and open questions; the grant for the author's original materials is in [LICENSE](../LICENSE). Do not merge or publish the draft release on the strength of this review alone.

## What changed

The former `mod/zscript/hud/arpg_statusbar.zs` was a close adaptation of UZDoom's GPL-3.0-or-later `zscript/ui/statusbar/hexen_sbar.zs`. This branch deletes that 305-line file, removes its `#include` from `mod/zscript.txt`, and removes `StatusBarClass = "ARPGStatusBar"` from `mod/MAPINFO`. UZDoom now loads its own Hexen status bar from the installed engine data. No copied status-bar source is packaged by the mod on this branch. The former file remains in Git history and on the older PR branch; this change does not erase already distributed copies.

UZDoom's own executable and data remain GPL-3.0-or-later. Running independently written ZScript under a GPL interpreter does not, by itself, establish that the ZScript is GPL-covered. The boundary between a mod and engine plug-in can depend on how tightly they combine and is not conclusively resolved here. The direct source copying was the clear GPL issue; its removal does not prove that every remaining file has been cleared.

## Remaining code review

The author reports that the remaining ZScript and launch scripts were made for HEXEN-ARPG with Codex assistance, without intentional third-party copying. A comparison of 24 remaining project ZScript files with 294 ZScript files extracted from installed UZDoom 5.0.3 found no exact run of six consecutive nonempty lines. Four-line hits were short, common language patterns. This heuristic can miss modified copying, other upstream versions, and sources outside UZDoom; it is supporting evidence, not a provenance guarantee. No other upstream copyright or SPDX notice was found in `mod/` or `tools/`. Review file origins and contributor records before release.

The mod refers to Hexen sprites, sounds, and textures by resource name at runtime. No original Hexen WAD, UZDoom binary, third-party map archive, or sound file is tracked. The seven sword PNGs have author confirmation of original creation and publication permission; the ring PNG is reproducibly generated by `tools/generate-ring-icon.ps1` from primitives. Neither permission is a GPL grant. Untracked sky textures and draft maps remain excluded pending review; see [asset review](asset-review.md).

## Rights decision and remaining question

The rights holder approved the project-specific [LICENSE](../LICENSE) and [RIGHTS.md](../RIGHTS.md) for original code, scripts, graphics, and documentation, with a narrower rule for patches containing copyrighted portions. The author has **not** consented to GPL-3.0-or-later for original project code or PNGs. These terms do not cover third-party work. The remaining question is whether any current ZScript use of UZDoom's APIs could make that code a combined work subject to GPL obligations. Mere use of a GPL interpreter, or the existence of a copied file in history, does not by itself decide that question. The historical adapted file retains its upstream notices and obligations; the new license does not relicense it. Verify any other outside contributions before public release.

The earlier draft release ZIP was replaced with a pre-license candidate from commit `fd3f5ef`; it excluded the copied status bar and included the gem fix. That candidate is now outdated because it lacks the approved rights documents. Rebuild it from the final reviewed commit. The ZIP must contain readable mod source, launch scripts, documentation, `LICENSE`, and `RIGHTS.md`, but exclude `HEXEN.WAD`, UZDoom binaries/data, third-party WADs, unreviewed assets, saves, local configuration, editor files, and the deleted status-bar source. Check the exact archive entry list and test extraction before publication.

## Technical release gate

See [native status-bar check](native-statusbar-check.md). The mod compiles and the Cleric's ordinary and fullscreen HUDs were observed with HP, both mana values, level, and XP. Fighter/Mage HUD, inventory, abilities, multiple resolutions, and save/load still need direct play testing. The built-in bar displays armor `0` where the old custom bar hid it; this is a visual difference, not a demonstrated gameplay change. Do not merge the PR or publish a Release until these checks are complete.
