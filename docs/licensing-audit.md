# Release licensing audit (pending)

This is a release checklist based on the files in `feature/independent-weapon-slots` as inspected on 2026-11-20. It records evidence and unresolved rights; it does **not** grant a license on behalf of any contributor. The author expressly declined to grant GPL-3.0-or-later rights for the project's original code and PNGs at this stage. Do not publish the draft release until the blockers below are resolved.

## UZDoom-derived status bar and the combined mod

`mod/zscript/hud/arpg_statusbar.zs` is an adaptation of UZDoom's `zscript/ui/statusbar/hexen_sbar.zs` (also present in the locally installed UZDoom data archive). A line diff against that source shows only 14 added and 5 removed lines; this is substantially copied code, not an independent implementation. Its original copyright holders and `SPDX-License-Identifier: GPL-3.0-or-later` header are retained. A dated HEXEN-ARPG modification notice has been added. UZDoom identifies its code as GPLv3 or later. [GPLv3](../LICENSES/GPL-3.0.txt) is included verbatim.

The status bar is loaded by `mod/zscript.txt`, selected by `mod/MAPINFO`, and exchanges data with other ARPG classes. For release planning **while that copied file remains**, treat the ZScript mod as one combined derivative work, not as a collection of independent files. GPLv3 section 5 requires a distributor of a modified source work to retain copyright/license notices, mark modifications and dates, and license the entire combined work under GPL-3.0-or-later (or a later GPL version chosen under the upstream grant). A GPL copy and SPDX line on the status-bar file alone do not satisfy that requirement. Merely placing independent programs together would be different, but does not describe this integrated ZScript mod.

**Engine versus mod:** The GPL status of UZDoom's executable does not automatically impose GPL on every independently written ZScript file that users load into it. The GNU GPL FAQ distinguishes programs merely interpreted by a GPL interpreter from tightly combined plug-ins. The legal boundary for a ZScript mod that calls engine APIs is not conclusively settled by this audit. The direct copying of UZDoom's status-bar source is the clear issue here regardless of how that boundary is drawn. Removing that copied source would remove this specific GPL-derived component; it would not prove that every remaining file is original or settle every engine/mod legal question.

The mod archive contains editable ZScript, configuration, launch scripts, and project graphics. If the GPL-derived status bar remains in a distributed build, source code for the combined covered code should accompany every downloadable mod ZIP, along with the GPL text and applicable copyright/modification notices. If a future build ships compiled or otherwise non-source code, provide the complete corresponding source and installation/build scripts by one of GPLv3 section 6's permitted methods. The engine and the buyer's `HEXEN.WAD` are separate dependencies and are not bundled; this audit does not purport to relicense either. GPL permission for UZDoom code also grants no rights to Hexen game art or third-party maps. Original PNGs have **not** been licensed under GPL by the author; whether a particular graphic is legally separable from covered code needs asset-specific review, not an automatic repo-wide assumption.

## Provenance categories and release paths

- **UZDoom-derived code:** `mod/zscript/hud/arpg_statusbar.zs` is GPL-3.0-or-later and retains upstream attribution. It cannot be relabeled as original or proprietary merely by moving it to another file or ZIP.
- **Project code and scripts:** The author reports that most other ZScript and launch scripts were created specifically for HEXEN-ARPG by the author with Codex assistance, with no intentional third-party copying beyond the status bar. This is useful provenance evidence, but not a line-by-line clearance of every file. No GPL grant for these original contributions is currently authorized.
- **Project graphics:** The seven sword PNGs are author-confirmed original and approved for publication; the ring PNG is generated by the project's geometric drawing script. Publication permission is not a GPL grant. Record separate explicit terms for images before release; do not mark them GPL by default.
- **External resources:** Hexen IWAD art/sounds/maps, UZDoom binaries/data, third-party WADs, untracked sky textures, and draft maps are not part of the cleared package. The mod may refer to resources in the user's own installed game at runtime.

**Path A — keep the current status bar:** Obtain GPL-compatible permission for all code that forms the combined mod, license the combined code accordingly, preserve notices, and ship corresponding source and GPL text. This is not authorized by the current rights holder decision. The copyright owner can generally license their own original code separately for a future commercial game, but cannot grant proprietary rights to UZDoom code or to any other contributor's work without permission. Treat graphics separately only where they are genuinely separable and their own terms permit the intended distribution.

**Path B — preferred for the present rights decision:** Replace the copied status bar with an independently authored implementation based on functional requirements, not a line-by-line rewrite of UZDoom source. Preserve the intended Hexen/Fighter/Mage and ARPG Cleric HUD behavior, then compile and playtest all affected modes, saves, and resolutions. Recheck the rest of the mod for copied upstream code. If clean, publish original project code and PNGs under explicit terms chosen by their owner; GPL text/attribution would remain only if some GPL-derived material still ships. This path has not been implemented or tested and must not be treated as cleared yet.

## Rights inventory and release blockers

1. **Rights decision:** The author has withheld a GPL grant for their original contributions. Do not release the current combined ZScript as though that grant existed. Either obtain an explicit compatible grant (Path A) or complete and validate an independent status-bar replacement (Path B). Confirm all contributors' rights and any additional borrowing in either case.
2. **Project notice:** After choosing a path, add a clear top-level `LICENSE`/`COPYING` or equivalent notice identifying exactly which code and assets carry which terms, their copyright holders, and any upstream attribution. If GPL-derived code remains, keep `LICENSES/GPL-3.0.txt` in both repository and ZIP. Do not present the whole repository or original PNGs as GPL-licensed without authorization.
3. **Source and archive:** Rebuild the ZIP from the reviewed branch after licensing changes. The ZIP attached to the unpublished GitHub draft release matches the inspected local copy (SHA-256 `42c54001106286157886f0794fd57a411169ca0d553f822f488821e429800381`). It contains the source tree and GPL text and no `.wad`, `.pk3`, `.pk7`, `.exe`, or `.dll` entry, but its `mod/zscript/loot/gems.zs` differs from the current branch and lacks the latest fix. The draft is stale and must not be published as the release asset. Recheck the exact rebuilt ZIP, including its source/notice files, against the release commit.
4. **Excluded work files:** Keep untracked `mod/assets/textures/sky/*` and `maps/first-tower.*` outside the archive. Their provenance is unresolved. No tracked `HEXEN.WAD`, original map archive, UZDoom executable, third-party WAD, or sound file was found. Runtime references to textures/sprites/sounds in a user's legally obtained IWAD do not place those binary assets in this repository.
5. **Other borrowed code:** A scan found no other explicit upstream copyright/SPDX header in `mod` or `tools`, but absence of a header is not proof of originality. Review contributor and copy/paste provenance for the rest of the code. Any additional borrowed material needs attribution and a license compatible with the combined GPL work.
6. **Interface notices:** GPLv3 section 5(d) may require Appropriate Legal Notices in interactive interfaces, unless the upstream program's interfaces lacked them. Verify how this applies to the adapted status bar and document the conclusion. Do not change gameplay or UI solely on an unverified assumption.

## Release package minimum after clearance

Package `Play.bat`, `Play-Custom-Map.bat`, `mod/` (including readable ZScript and project graphics), `tools/` (including launcher/config and relevant generators), `README.md`, `README.ru.md`, an explicit rights notice covering code and PNGs, and provenance/attribution documentation. Include `LICENSES/GPL-3.0.txt` and upstream notices if any GPL-derived code remains. The archive must exclude UZDoom binaries, `HEXEN.WAD`, copyrighted original map data, unreviewed sky/map work files, saves, personal paths, and editor files. A published GitHub source tree alone is not a substitute for checking what the downloadable ZIP contains.
