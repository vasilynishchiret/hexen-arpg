# Ассеты оружия

Файл `mod/TEXTURES` объявляет `ARAX` для меча в руках и `ARAW` для меча на земле. `ARAWA0` теперь использует отдельный пользовательский PNG `mod/patches/arpg_sword/WBLADEA0.png` размером 28 × 41 со смещением 12, 37. Исходный PNG не преобразуется и не перезаписывается. Топор на земле берёт lump `WFAXA0` (состояние `WFAX A`) из установленного `C:\Games\UZDoom\HEXEN.WAD`, молот — `WFHMA0` (`WFHM A`) из того же WAD; коммерческие ресурсы не копируются в репозиторий.

Меч в руках использует пользовательские `FBLADEA0.png`, `FBLADEO0.png`, `FBLADEP0.png`, `FBLADEQ0.png`, `glow_l.png` и `glow_m.png`. Кадр N пока берётся из исходного `FAXEN0`; остальные временные ссылки на оригинальные кадры сохранены в `TEXTURES`. Активная анимация меча находится в `mod/zscript/weapons/equipped.zs`, состояние `SwordFire`. Один вызов `A_ARPGStrike` приходится на каждый взмах, электрический эффект попадания — `ARPGSwordPuff` из `sword_puff.zs`.

Чтобы заменить очередной кадр меча, добавьте новый прозрачный PNG в `mod/patches/arpg_sword/`, затем измените ссылку `Patch` соответствующего `Sprite ARAX...` в `mod/TEXTURES`. При изменении размеров также обновите размеры виртуального спрайта и проверьте его смещение в UZDoom. Не меняйте исходный `HEXEN.WAD` и не удаляйте существующие пользовательские PNG.

Для сверки оригинального Fighter начните отдельную игру за Fighter, в консоли выполните `give FWeapAxe` и `give Mana1`. Класс `FWeapAxe` и его исходные спрайты мод не переопределяет.
